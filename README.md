# 微信射击小游戏（iPhone 可玩）

这是一个纯前端 H5 射击小游戏，适配手机触控与微信内置浏览器。只要把项目部署成 HTTPS 链接，就能在苹果手机微信里直接打开游玩。

## 本地运行

```bash
python3 -m http.server 8080
```

然后访问：

- 电脑：`http://localhost:8080`
- 手机（同一局域网）：`http://你的电脑IP:8080`

## 操作方式

- 左右按钮：移动战机
- 开火按钮：连续射击
- 在画布上拖动：移动并自动开火
- 敌人漏过底部会扣生命，碰到玩家直接结束

## 部署成可分享链接（推荐 Vercel）

1. 把本目录推到 GitHub。
2. 打开 [https://vercel.com](https://vercel.com) 并导入该仓库。
3. 选择默认静态站点配置并部署。
4. 获得 `https://xxx.vercel.app` 链接，发到微信即可在 iPhone 打开。

> 提示：微信中请使用 HTTPS 链接，体验会更稳定。
